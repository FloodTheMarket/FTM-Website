# FTM Logo System

FTM stands for Flood The Market.

This logo system is designed to feel premium, minimal, monochrome and operator-led. The wave is intentionally restrained and integrated into the F mark as a motion signal, avoiding a loud water-brand or generic marketing-agency look.

## Files

- `ftm-wordmark-light.svg` — black wordmark on warm light background
- `ftm-wordmark-dark.svg` — warm white wordmark on black background
- `ftm-wordmark-transparent-light.svg` — black transparent wordmark for light layouts
- `ftm-wordmark-transparent-dark.svg` — warm white transparent wordmark for dark layouts
- `ftm-icon-light.svg` — black icon mark on warm light background
- `ftm-icon-dark.svg` — warm white icon mark on black background
- `ftm-favicon.svg` — favicon-sized icon mark
- `ftm-logo-system-preview.png` — quick preview sheet

## Usage

Use the full wordmark where there is enough horizontal space. Use the icon mark for favicons, avatars, social profile images, app icons and tight navigation placements.

Keep the logo monochrome. Avoid gradients, drop shadows, bright blues or heavy colour treatments.
